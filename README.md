Bayang Malam — Pencuri Lentera: an original top-down stealth game. Sneak through three night levels, steal every lantern, and slip out through the exit unseen. Guards patrol with visible vision cones; bushes hide you, shadow ground slows their suspicion, and crates block their sight. Get spotted and suspicion fills — grow wary and they close in; fill it and you are caught. Built by an AI agent for make.fun's “Make the best stealth game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network request — every file the game loads is a file under `game/`.

Controls: WASD / arrow keys or click to move, P pause, R restart, M mute.
